# 坤坤皮肤

一个给 DeepSeek Harness 用的外观插件（Web 与桌面端共用同一套 Web 客户端）。

## 它做什么

- 在界面右下角固定显示坤坤立绘，纯装饰、`pointer-events: none`，不会挡住点击和滚动。
- 设置面板有两个入口：**设置 → 坤坤皮肤**，以及 **插件 → dsh-kunkun** 的配置区，两处是同一个组件：
  - 一个开关，控制是否显示立绘（关掉后设置入口仍然保留）；
  - 立绘样式选择：静态坤坤、动图清单里的每一张动图、自定义图片；
  - 上传按钮，支持 GIF / WebP / PNG / JPEG（≤ 5 MB），存在浏览器 IndexedDB 里，「移除」可删除；
  - 动图位置：右下角小立绘，或铺在整个界面背景中（半透明，从右到左逐渐虚化）。
- 内置素材由插件 Host 半边用一条 prefix 静态路由伺服整个 `assets/` 目录（`/plugins/dsh-kunkun/assets/*`），浏览器正常缓存；新增素材只要放文件，不用改代码。上传的图片只留在本机浏览器里，不联网。
- 动图统一登记在 `assets/anim/manifest.json`：`frames ≥ 2` 是横向精灵条，滑块可以调速；`frames: 1`（或省略）表示原图直接播放，滑块对它无效。`node scripts/make-anim.mjs <源文件>` 能把 GIF / MP4 / WebM / WebP 转成精灵条并写进清单，加 `--native` 则原样拷贝。
- 输入框工具排（`conversation.input.right`，模型选择器旁）有一个滑块，同时干两件事：拖动时实时改变动图播放速度（30%–300%，任意值）；滑轨按当前模型的档位数 N 均分成 N 个区域，旋钮落在哪个区域就是哪个推理等级，松手时通过官方 ModelDirectory 提交该档位。滑块永不消失：模型没有 ≥ 2 个档位（常见于第三方模型）、子代理会话或服务不可用时，降级为纯调速模式，照样控制动图。设置面板底部有诊断框，显示滑块的注册、props 解析和渲染模式。

## 它不做什么

- 不改配色、字体、布局，也不动界面其它部分。
- 不改宿主主题偏好。

## 安装

```sh
dsh plugin add github:Junan-X/dsh-kunkun
```

安装后重启 DSH 生效。
